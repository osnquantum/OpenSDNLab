# OpenSDNLab

Version: 0.1.0-alpha

## Vision

OpenSDNLab is an interactive Software Defined Networking laboratory platform
for education and research.

The platform allows users to:

- Design custom network topologies
- Configure IPv4, IPv6, or Dual Stack networks
- Connect to SDN controllers
- Generate network traffic
- Monitor QoS and SDN metrics
- Visualize the network in real time
- Export reports and experiment data
- Replay previous experiments

---

## Design Principles

- No hardcoded topology
- No hardcoded IP addresses
- Everything configurable
- Plugin-based architecture
- Database-driven
- Modular design
- Cross-platform where possible
- Educational first
